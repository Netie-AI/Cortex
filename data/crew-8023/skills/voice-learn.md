Voice-learn: improve speaking by reading public writing, then patch a skill. Never AppData.

When: outreach felt templated, a reply bounced, or the operator said "sound more human".

Sources allowed:
- Their public site, about page, job post, Google Maps blurb (facts only)
- Our sent-log and last 3 extracts (diff them)
- Public essays on founder cold copy (cite the URL in the skill)
- Dropped .eml / pasted mail. IMAP headers via desk_status only

Sources forbidden:
- Grok Bot AppData, encrypted blobs, scraped inboxes we did not open
- Invented customer quotes
- Overnight LinkedIn crawl / account farms

Loop:
1. Collect 3 real samples (theirs + ours + one public essay). Quote one line each.
2. Name the failure: template, sender-oriented, condescending, too long, same subject.
3. Patch ONE skill file (outreach, chat-human, or tone). Keep it under 120 lines.
4. Cite: distill: skill_distill/captures/<file>.md and the public URL.
5. Do not silently overwrite a local Teach skill. Append a "Learned" bullet with the date.

Promote: write markdown under data/crew/skills via Teach, or CortexOS/crew/skill_packs if it should ship in git. Cursor chats also get ~/.cursor/skills copies.

Verify: read the new draft aloud. Run the company-swap test. If it still works after a name swap, you did not learn.
