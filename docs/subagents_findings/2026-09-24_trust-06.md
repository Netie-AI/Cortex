# TRUST-06: EXIF-GPS privacy test runs without piexif and covers the persisted photo (#262)

Epic: #256 EPIC-TRUST-01. Base: 4f74c0f.

## Expected vs actual

- Expected: the F7 choke-point (intake strips GPS EXIF before a photo is stored) is proven on every install, on the bytes intake writes to disk.
- Actual (base): `tests/dms/test_v0_warehouse.py::test_exif_gps_stripped` built its fixture with `pytest.importorskip("piexif")`. piexif is not in any extra, so the test always skipped (VERIFIED: `SKIPPED [1] ... could not import 'piexif'`). Even when it could run, it called `strip_exif_gps` itself and handed the already-clean bytes to intake, then asserted nothing about the stored file. Removing the strip from intake would not have failed it.

## Root-cause class

Gate honesty: a privacy control whose only test depended on an optional package that is never installed, and whose assertion targeted an intermediate value instead of the stored artifact.

## Fix (tests only)

- `tests/dms/test_v0_warehouse.py`: the GPS JPEG fixture is built with Pillow `Image.Exif` and the GPS IFD (0x8825); no importorskip. The test now submits the raw GPS-bearing bytes to `intake_item`, reads the file back from `photos_dir()` via the returned `photo_uri`, and asserts `has_gps_exif` is False and the image decodes at its original size. It also still asserts the raw bytes report GPS True. `ruff --fix` sorted two pre-existing unsorted import blocks in the same file (no behaviour change).
- `tests/security/test_photo_sanitize.py` (new):
  - P1 pre-strip fixture bytes report `has_gps_exif` True and carry the GPS IFD; a clean JPEG reports False.
  - P2 GPS JPEG through intake: stored file differs from input, has no GPS IFD, verifies and loads as a JPEG of the same size, and the item and ledger `photo_uri` point at that file.
  - P3 no-GPS JPEG through intake is accepted (ledger event `item.intake`) and persisted as a readable JPEG (no false-positive refusal).

No source file changed. `photo_sanitize.py`, `intake.py`, `pyproject.toml` untouched.

## Invariant

A photo persisted by DMS intake never carries GPS EXIF, and a legitimate photo without GPS is never refused.
