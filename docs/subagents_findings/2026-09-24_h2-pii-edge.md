# H2-PII-EDGE: redactor edge cases, and redact before the router sees the prompt (#250)

- **Date:** 2026-09-24
- **Keywords:** pii, redaction, nric, mykad, fullwidth, NFKC, lookaround, judgment model, kev, decision backend, invoke_routed_completion, cost gate, estimate_node_cost, redact_for_routing, fail closed, no false positive corpus
- **Main idea:** `default_redact` now uses digit lookarounds instead of `\b` (so `user_S1234567D`, `S1234567D_x` and `ic900101145678` are caught), accepts a MyKad with matching space or dash separators, and folds fullwidth digits and letters to ASCII before matching with a width-preserving fold so spans still index the caller's text. Both `router.route` calls in the engine are redacted first: `invoke_routed_completion` (execution) and, after the verifier finding, `dag_runner._price_one_call` (the pre-execution cost gate that runs whenever `run_dag` has a finite `workflow_cost_ceiling_myr`) through a shared `executor.redact_for_routing` helper, so `JudgmentModel.decide`, any decision backend and a `KevHttpBackend` POST only ever see placeholders on either path. A 29-string non-PII corpus comes out byte-identical through the redactor and through `run_dag`.
- **Verify:** `python -m pytest tests/test_execution/test_pii_edge_cases.py -q -p no:cacheprovider` (81 tests) then `python -m pytest tests/ -q -p no:cacheprovider`
- **Does not prove:** that the pack redactor (`packs/dms/security/pii.py`, not a write target) has any phone-number edge cases fixed; it reuses `NRIC`, `MYKAD` and `detect_spans` so it inherits the lookaround and fullwidth fixes, but that is not asserted here beyond the existing `tests/dms/test_f7_security.py`. NER and token-vault behaviour untouched.

## Root-cause class

1. Boundary assertion mismatch: `\b` is a word/non-word transition and `_` is a word character, so identity numbers glued to `_` or letters were never bounded. Fix: `(?<!\d)` and `(?!\d)`; only a digit neighbour invalidates an identity number, because a longer digit run is a different thing (a card number), not a hidden NRIC.
2. Pattern too narrow: MyKad separator was dash-or-nothing. Fix: `(?P<sep>[- ]?)` with a `(?P=sep)` backreference so both separators must agree; `900101-14 5678` stays unredacted on purpose (it is in the no-false-positive corpus).
3. Character-set blindness: ASCII classes cannot see fullwidth forms. Fix: `fold_for_matching` folds each code point through NFKC only when the result is one code point, so `len(folded) == len(text)`; `detect_spans` matches the folded text and reports spans (and `RedactSpan.text`) against the original. A ligature such as `ﬁ` (NFKC expands to two code points) is left alone, asserted by `test_fold_for_matching_preserves_length_and_indexes_original`. Anything outside a span is byte-identical.
4. Ordering at the choke-point: GH-01 put redaction after `route()` because the T0 early return needed `routed.tier`. Fix: redact first; the router is handed the redacted adapter prompt (every caller in this repo builds `ModelRequest.prompt` and `AdapterRequest.prompt` from the same string: `dag_runner.py:154-167`, `agent_task.py:265-282`), so on the execution path the raw `model_req.prompt` does not reach a backend and the registered redactor is called exactly as often as before (system, prompt). `_log_decision` receives the redacted request; `decision_log` already strips `content` to a hash, so the JSONL was never a leak.
5. A second `route()` call site (verifier finding): the cost gate is a separate entry into the router that `invoke_routed_completion` never sees. Fix: `executor.redact_for_routing(model_req)` returns the request with `prompt` redacted (fail closed, same `max_tier == T0` empty-prompt exception as the execution path), and `_price_one_call` calls it before `router.route`; the token estimate for pricing is taken on the redacted prompt, matching what `invoke_routed_completion` later estimates. `grep -n "router.route\|\.route(" CortexOS/` shows these are the only two `ModelRouter.route` call sites in the engine; both now redact first. There is no third path.

- Fail closed.
