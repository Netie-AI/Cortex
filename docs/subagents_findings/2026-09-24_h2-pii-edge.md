## Root-cause class

1. Boundary assertion mismatch: `\b` is a word/non-word transition and `_` is a word character, so identity numbers glued to `_` or letters were never bounded. Fix: `(?<!\d)` and `(?!\d)`; only a digit neighbour invalidates an identity number, because a longer digit run is a different thing (a card number), not a hidden NRIC.
2. Pattern too narrow: MyKad separator was dash-or-nothing. Fix: `(?P<sep>[- ]?)` with a `(?P=sep)` backreference so both separators must agree; `900101-14 5678` stays unredacted on purpose (it is in the no-false-positive corpus).
3. Character-set blindness: ASCII classes cannot see fullwidth forms. Fix: `fold_for_matching` folds each code point through NFKC only when the result is one code point, so `len(folded) == len(text)`; `detect_spans` matches the folded text and reports spans (and `RedactSpan.text`) against the original. A ligature such as `ﬁ` (NFKC expands to two code points) is left alone, asserted by `test_fold_for_matching_preserves_length_and_indexes_original`. Anything outside a span is byte-identical.
4. Ordering at the choke-point: GH-01 put redaction after `route()` because the T0 early return needed `routed.tier`. Fix: redact first; the router is handed the redacted adapter prompt (every caller in this repo builds `ModelRequest.prompt` and `AdapterRequest.prompt` from the same string: `dag_runner.py:154-167`, `agent_task.py:265-282`), so the raw `model_req.prompt` cannot reach a backend by any path and the registered redactor is called exactly as often as before (system, prompt). `_log_decision` receives the redacted request; `decision_log` already strips `content` to a hash, so the JSONL was never a leak.

## Invariant applied

- CortexOS never imports `packs.*` (asserted by AST in the new file for both write targets; `lint-imports` 3 kept, 0 broken).
- Fail closed. A raising redactor now aborts BEFORE routing: the spy judgment model and spy backend record zero calls, the adapter receives nothing, and the ledger row is `status='error'` at the request's `default_tier` (nothing was routed, so there is no `routed.tier`; a small `_UnroutedCall` stands in for the decision log). The one exception is `max_tier == T0`: no model can ever be called, so the request is routed on an empty prompt instead of failing, which keeps `tests/test_execution/test_dag_pii_redaction.py::test_t0_tier_skips_adapter_and_never_needs_redaction` green while still keeping raw text away from the backend (asserted: `JudgmentRequest.content == ""`).
- Legal floor survives redaction: `[REDACTED:nric]` contains the legal term `nric`, so a loan agreement with a T0 backend still lands at T2 (ledger row, node tier, adapter model all asserted). Consequence worth knowing: a prompt whose only legal signal is an identity number is now routed at T2 minimum, where before the raw digits carried no keyword. That is the intended direction (identity data is at least as sensitive as a contract).
- No false positives: 29 strings (quantities, PO/SO/INV ids with `-` and `_`, ISO dates and timestamps, batch/lot codes with 7 digits, a ten digit ref, a phone number, a shelf code `S123`, a tracking id `T12345678`, an unassigned MyKad place code `17`, mixed separators, CJK text with fullwidth `Ｑ１ 销量 １２３`, empty and whitespace) are asserted byte-identical through `default_redact` and, joined, through `run_dag` into the adapter request and the run output.
