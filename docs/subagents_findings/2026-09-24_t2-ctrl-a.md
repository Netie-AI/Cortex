# T2-CTRL-A: role gates on the routine, goal and race routes (#263)

Epic #263 (EPIC-TRUST-02). Follows TRUST-01 (#256, `docs/subagents_findings/2026-09-24_trust-01.md`). Base: 636e99b.

## Expected vs actual (before this change)

- Expected: a caller with no key gets 401 on every route in `CortexOS/api/routine_routes.py`, `CortexOS/api/goal_routes.py` and `CortexOS/api/race_routes.py`. A key whose role is too low gets 403. A missing authorizer gets 503. None of these refusals reaches a handler or changes any state.
- Actual: none of the three files had an auth dependency. Any caller that could reach the port could create, edit, run, fire and delete routines, force a scheduler tick, rewrite the bound enterprise goal (including its hard constraints and autonomy level), record seeks and commitments, compact telemetry, and start races through `/api/engine/auto`. A keyless request with a schema-invalid body got 422 (the schema) instead of 401.

## Root-cause class

Missing authorization on an engine route plane. Same class as TRUST-01: the RBAC lives in `packs/dms/security/api_auth.py`, which these engine modules may not import, and they were left open. TRUST-01 added the port; these files had not been wired to it yet.

## Fix

Reuses `CortexOS/security/auth_port.require_role` exactly as `CortexOS/api/app_routes.py` does: module-level `_VIEWER` / `_STEWARD` / `_ADMIN` dependency lists passed as `dependencies=` on each route. No new auth code, no `packs.*` import, handlers unchanged. 401 / 403 / 503 come from the port, so the semantics match TRUST-01.

| Route | Role | Why |
|---|---|---|
| `GET /api/routines`, `GET /api/routines/{rid}`, `GET /api/routines/{rid}/runs` | viewer | reads |
| `POST /api/routines/draft` | viewer | deterministic preview, saves nothing |
| `POST /api/routines`, `PATCH /api/routines/{rid}`, `POST .../pause`, `.../resume`, `.../run`, `.../fire` | steward | mutate or run one routine |
| `POST /api/routines/pause-all` | steward | the stop switch should not be harder to reach than what it stops |
| `POST /api/routines/tick`, `POST /api/routines/resume-all`, `DELETE /api/routines/{rid}` | admin | bulk run, bulk re-enable, destroy |
| `GET /api/goals`, `GET /api/goals/{id}`, `.../seeks`, `.../values`, `GET /api/commitments`, `GET /api/engine/telemetry` | viewer | reads |
| `POST /api/engine/osr` | viewer | classify-only, no write |
| `POST /api/engine/seek`, `POST /api/goals/{id}/outcome`, `POST /api/commitments/scan`, `.../{cid}/close`, `.../{cid}/dismiss` | steward | write seek, audit, value and commitment rows |
| `POST /api/goals`, `PATCH /api/goals/{id}`, `DELETE /api/goals/{id}` | admin | the bound goal's constraints and autonomy level govern what the engine may do on its own |
| `POST /api/engine/telemetry/compact` | admin | deletes raw telemetry rows |
| `POST /api/engine/auto` | steward | runs work and spends on it |
| `GET /api/engine/scoreboard`, `GET /api/engine/scoreboard/{family}` | viewer | reads |

The ticket-specific lines in the shared template (actor/approver from the caller, reaping on read paths, host paths in bodies, archive limits) belong to T2-CTRL-B, T2-DMS and T2-RESP. None of the routes in these three files takes an actor or approver from the body, reaps runs, or handles archives. The refusal bodies are the port's fixed strings, and the tests assert they carry no host path.

## Invariant

Every route registered by the three files refuses before its handler runs unless the registered authorizer grants that route's minimum role. No authorizer means refuse. CortexOS still imports no `packs.*`.
